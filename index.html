📊 คู่มือติดตั้ง Google Sheets Cloud Database & โค้ด Apps Script
💡 ทำไมต้องใช้ Google Sheets เป็นฐานข้อมูล?
ข้อมูลจะถูกส่งขึ้น Google Cloud อัตโนมัติ ป้องกันข้อมูลหาย และสามารถเปิดดูผ่านมือถือหรือแท็บเล็ตได้ทุกที่ทุกเวลา โดยแยก 4 หมวด: Dashboard_Overview, Engine_Runs, LINE_OA_History และ PM_Maintenance
  1. สร้าง Google Sheet ใหม่: เข้าเว็บ sheets.new ตั้งชื่อชีตตามต้องการ เช่น Firetrol_MarkIIXG_Database
  2. เปิดตัวแก้ไข Apps Script: ที่เมนูด้านบนของ Google Sheet ไปที่ ส่วนขยาย (Extensions) ➔ Apps Script
  3. วางโค้ด: ลบโค้ดเดิมในหน้าต่างออกทั้งหมด แล้วกดปุ่ม "📋 คัดลอกโค้ด Apps Script" ด้านล่างนี้ไปวาง
  4. บันทึก: กดปุ่มรูปแผ่นดิสก์ บันทึกโครงการ (Save project)
  5. Deploy เว็บแอป (ขั้นตอนสำคัญที่สุด):
    • กดปุ่มสีน้ำเงิน ทำให้ใช้งานได้ (Deploy) ➔ การทำให้ใช้งานได้รายการใหม่ (New deployment)
    • กดรูปฟันเฟือง (Select type) เลือก เว็บแอป (Web app)
    • คำอธิบาย (Description): AI-FPAS Database API
    • ดำเนินการในฐานะ (Execute as): ฉัน (Me - อีเมลของคุณ)
    • ผู้ที่มีสิทธิ์เข้าถึง (Who has access): ทุกคน (Anyone) <-- ต้องเลือกอันนี้เท่านั้น เพื่อให้เว็บส่งข้อมูลเข้าชีตได้
    • กดปุ่ม ทำให้ใช้งานได้ (Deploy) แล้วกด ให้สิทธิ์เข้าถึง (Authorize access) บัญชี Google ของคุณ
  6. คัดลอก URL: คัดลอก URL ของเว็บแอป (Web App URL) ที่ลงท้ายด้วย /exec นำมาวางในช่อง "Google Apps Script Web App URL" ในหน้าตั้งค่านี้ แล้วกดบันทึกและทดสอบการเชื่อมต่อได้ทันที!
